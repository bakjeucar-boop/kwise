## 6. 새 창이 지킬 것

- **문장을 새로 쓸 때 기본요금이 무엇에 매이는지 적지 않는다.** 적어야 하면 갈래를 아는 자리에 둔다. 새 못이 계약형·하한형 두 벌의 화면·PPT·Excel·Word 글자를 문다.
- **새 못은 pytest 분할의 산출물 갈래에 있다**(「pytest 분할 실행」 절 · ① 엔진 무시 목록 여덟). 사전 취득 기상(`data\weather\`)을 쓰려고 시험 안에서 `KWISE_WEATHER_DIR` 를 푼다.
- **`git stash` 는 워크트리 줄끝을 바꾼다.** CRLF 수를 잴 판이면 stash 전에 센다.
- **`output\casestudy_YYYYMMDD.xlsx` 는 저장소에 있다.** 같은 날 케이스 스터디를 다시 돌리면 덮어쓴다 — 칸 단위로 맞대 소요 칸만 갈렸으면 `git checkout` 으로 저장소 판(깨끗한 판)을 되살린다(S168~S170).
- **이 셸에서 `git commit -F -` 에 여러 줄을 흘리면 안 먹는다.** 메시지를 스크래치 파일로 쓰고 `git commit -F 파일` 로 건다.
