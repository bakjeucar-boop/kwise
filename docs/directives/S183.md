1절 — 확인 안 한 못을 전수로 되돌려 확인한다

되돌림은 파일 하나씩 한다. git checkout <rev> -- 경로 는 인덱스에도 올리므로
돌릴 때는 git checkout HEAD -- 경로 로 둘 다 되돌리고 git status 를 본다.
해당 시험 파일만 돌린다 — 전체 pytest 를 여기서 돌리지 않는다.

1-1  docs\HANDOVER.md 6절 못 표를 전수로 읽어, 「마지막으로 되돌려 확인한
     세션」 칸이 비었거나 「확인 안 했다」 인 못을 이름으로 뽑는다. 수를 먼저
     적는다.
1-2  1-1 의 못을 하나씩 되돌려 확인한다. 못마다 무엇을 옛 글자로 되살렸고
     어디서 빨개졌는지 한 줄씩. **안 빨개지는 못이 있으면 그 사실을 적고 그
     못을 이 판에서 고칠지는 1-6 이 정한다.**
1-3  「추가 절감」 이름이 S182 뒤에 어떤 꼴로 서 있는지 값으로 낸다 —
     src\ 와 tests\ 를 전수로 훑어 그 말이 서는 자리를 이름과 함께 적는다.
     **표(worksheet)에 선 이름이 무엇인지 글자 그대로 옮겨 적고, 그 이름이
     원인(하향 몫)을 말하는지 값으로 판정한다.** 말하면 이름만 미해결에
     올린다 — 이 판에서 글자를 안 고친다.
1-4  1-3 에서 「조합 시 추가 절감」 글자가 갈리면 빨개지는 못이 있는지 값으로
     낸다. 없으면 그 사실을 적는다.
1-5  되돌림이 전부 원복됐는지 git status · git diff 로 확인한다.
1-6  1-2 에서 안 빨개진 못이 **둘 이하면 이 판에서 고친다.** 셋 이상이면
     안 고치고 이름으로 올린다 — 한 판에 몰아 잡는 자리가 따로 있다.
     어느 쪽으로 갔는지 수와 함께 적는다.
