**사람이 정한 것 — 그대로 선다** (S222 가 HANDOVER 5절에 앉혔다고 보고했다 —
실물에서 먼저 확인하라).
  전력삼각형은 가로 · 세로 같은 눈금(1:1)으로 고정한다. 역률 100 벌의 세로
  범위가 이것으로 함께 풀리는지 값으로 본다. 안 풀리면 범위는 고치지 않는다.

  · 「1:1 은 축 상자 높이만 바꾸고 범위는 못 바꾼다」 · 역률 100 벌 세로 범위

  · 화면 역률 85 · 92 벌은 못 봤다

이 판의 못 박힌 안전한 쪽.
  · **저장소 코드를 안 고친다.** 재는 코드 · 그리는 코드는 스크래치 `.py` 로
    만들어 `.venv\Scripts\python.exe` 로 돌린다.
  · **범위를 손으로 적는 방법은 재는 대상에 넣지 않는다** — 사람이 이미 닫았다.
  · **글자를 새로 세우거나 글자 내용을 바꾸는 방법은 재지 않는다.** 각도 글자의
    자리를 옮기는 방법만 잰다.
  · **겹침 · 잘림은 눈으로만 적지 않는다** — 글자와 선의 경계 상자 좌표로 낸다.
    png · 스크린샷은 그 값을 확인하는 짝으로 둔다.
  · 세션 도중 사람에게 묻지 않는다. 고르지 않는다 — 방법마다 값을 낸다.
  · **git stash 를 쓰지 않는다. S140 스태시를 지우지 않는다.**
  · **heredoc · `python -c` · `Set-Content` · `Out-File` 을 쓰지 않는다.**
    긴 출력은 `tools\run_tool.py --tail` 로 받는다 · `pytest_counts.py` 는
    인자 하나씩 · `deck_words.py` 는 온 경로 · `run_tool` 에 `.py` 를 직접
    주지 않는다. **파이프를 썼으면 쓴 자리마다 「무엇을 보려고 · 왜 도구로
    못 했나」 를 적는다.** 커밋 메시지는 편집 도구로 지은 `.txt` 로
    `git commit -F`.
  · **덱 19벌 뜨기를 하지 않는다** — 필요한 벌만 `tools\render_deck.py` 로.
    앱을 띄우면 포트를 적고 내린 뒤 닫힌 것을 확인한다. **벽시계를 절마다 잰다.**
  · 전체 pytest 는 안 돌린다 — 코드를 안 고친 판이다. 기록 묶음만 돌린다(5절).
