S191 — 「어느 장에 있다」 를 안 무는 못 둘을 고치고,
       화면 문구 후보를 png 로 찍어 사용자에게 넘긴다

1절은 고치는 절이고 2절은 찍는 절이다 — 2절은 한 글자도 안 고친다.
세션 도중 사람에게 묻지 않는다. **2절 끝에 앱을 내리지 않는다** — 사용자가
그 앱을 열어 문구를 본다. 포트 확인은 이 판의 마무리에서 빼기로 사람이 정했다.

이 판의 못 박힌 안전한 쪽 여덟.
  · 계산을 안 고친다. 계산 다섯 폴더(tariff · measures · diagnose · pv ·
    compare)는 0줄이다.
  · 금액이 한 원이라도 움직이면 그 자리에서 멈추고 되돌린 뒤 값을 낸다.
    회귀값 여덟도 같다. 기대값을 갱신하지 않는다.
  · **화면 문구를 한 글자도 안 고친다.** 2절은 찍기만 한다 — 고치거나
    줄이거나 자리를 옮기지 않는다. 감사 네 수가 갈리면 멈추고 값을 낸다.
  · 1절이 고치는 것은 시험이지 산출물이 아니다. 못이 무는 자리에 글이
    없어서 빨간 것이면 고치지 말고 값을 내고 이름으로 올린다.
  · **2절에서 조건을 세워야 서는 후보는 안 찍는다.** 이름과 지금 글자만
    내고 「조건 필요」 로 적는다. 조건 벌은 다음 판이 따로 세운다.
  · 범위 밖에서 걸리는 것은 안 고치고 이름만 올린다.
  · 되돌려 확인은 src\ 를 고치지 말고 스크래치 monkeypatch · plugin 으로
    한다. 부득이 돌렸으면 git checkout HEAD -- 경로 로 되돌리고
    git status 를 본다.
  · 파일 수정도 재는 스크립트도 셸에 태우지 않는다. 스크래치 .py 로 만들어
    .venv\Scripts\python.exe 로 돌린다.

원인·전제를 미리 적지 않았다. 앞 판 보고의 수는 값이 아니라 다시 잴 것으로
다룬다 — 줄 번호와 이름은 지금 파일에서 다시 찾는다.

1절 — 「어느 장에 있다」 를 안 무는 못 둘을 고친다

S190 1-5 가 둘을 이름으로 올렸다 — 이름에 자리를 적고 범위를 안 무는
못이다. S190 이 Word 마지막 장 못에 한 것과 같은 꼴이다.

1-1  둘의 지금 이름과 무는 것을 코드로 낸다 — 어느 글을 어느 범위에서
     찾나. 자리를 잡는 코드가 있는지, 없으면 그 사실을 적는다.
1-2  못마다 그 글이 실물에서 **어느 자리에 서는지 전수로** 낸다. 이름이
     말하는 자리 밖에도 서는지 본다. **벌 하나가 아니라 종별이 갈리는
     벌 둘 이상**에서 본다 — 고른 벌 이름을 적는다.
1-3  못을 고친다. 자리를 무는 꼴로 바꾼다. **시험만 고치고 src\ 는 안
     고친다.** S190 이 쓴 도우미가 여기에 쓰이면 다시 짓지 말고 부른다 —
     같은 일을 두 자리에서 하지 않는다.
1-4  못마다 되돌려 확인한다. 셋을 다 본다.
       · 그 글을 통째로 빼면 빨간가
       · **이름이 말하는 자리에서만 빼면 빨간가**(이 판의 본체다)
       · 다른 자리에만 두고 이름이 말하는 자리에서 빼면 빨간가
     옛 꼴에서 초록이던 갈래를 함께 적는다. 안 빨개지는 갈래가 있으면
     그 사실과 까닭을 값으로 적고 고치지 않는다.
1-5  **같은 모양이 또 있는지 전수로 다시 센다.** S190 이 둘을 찾았고 이
     판이 그 둘을 고친다 — 셋째가 있으면 뿌리를 볼 자리다. 수를 적고,
     있으면 고치지 말고 이름으로 올린다.
1-6  되돌림이 원복됐는지 git status · git diff 로 확인한다.
