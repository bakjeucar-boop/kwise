S214 — ㅅ 뿌리의 남은 쪽을 닫는다 — 12개월 환산값에 이름을 단다

**이 판은 글자 판이다. 금액 0 이다.**
  ① **어느 자리가 12개월 환산값이고 어느 자리가 기간 값인지 값으로 가른다.**
     앞 판이 「연」 쪽 365자리를 닫았고 「연간 …」 이 남은 자리를 다섯 무리로
     냈다 — **그 무리와 수도 다시 잴 것이다.**
  ② **환산값 자리에 이름을 단다.** **사람이 정했다 — 「12개월 환산」 이다.**
     **「연간」·「연」·「연중」 을 안 쓴다.** 기간 값 자리에는 S188 정본
     그대로 「기간」 을 쓴다.
  ③ **12개월 미만 경고 두 꼴을 정리한다** — 앞 판이 「둘 다 코드에게 하는
     말」 이라 냈다. **기준은 S207 이 세운 것이다** — 그 벌에서 참인 말만
     남기고 제도 설명은 매뉴얼로 보낸다.

**앞 판과 같은 성격이다 — 고객이 보는 글자를 고치고 값은 안 고친다.**
세션 도중 사람에게 묻지 않는다.

**울타리에 하한이 있다.** 1절이 센 「고칠 자리 수」 다. 앞 판처럼
**코드 자리 수와 실물 자리 수를 갈라 센다.** 적게 닫으면 **자리마다 왜
못 했는지 값으로 낸다.** 「안전해서 안 했다」 는 까닭이 아니다.

이 판의 못 박힌 안전한 쪽 열여섯.
  · **값을 만드는 줄을 안 고친다.** 12개월로 환산하는 계산 자체를 안
    건드린다 — 이 판이 고치는 것은 **그 수를 무엇이라 부르는가**다.
    요금 산식 · 요금적용전력 · 역률 · 초과부가금 · 태양광 · ESS · DR 의
    값을 만드는 줄은 0줄이다.
  · **금액이 한 원이라도 움직이면 멈춘다.** 회귀값 여덟 · 케이스 판정
    174 · 덱 19벌 수치 조각 전수가 다 불변이어야 한다. 움직이면 되돌린
    뒤 **어느 벌 어느 칸이 얼마에서 얼마가 됐는지** 전수로 낸다.
  · **환산값인지 기간 값인지는 값으로 가른다 — 글자로 짐작하지 않는다.**
    「연간」 이 붙었다고 환산값이라고 보지 않는다. **가름이 값으로 안 서는
    자리는 안 고치고 이름으로 올린다.**
  · **낱말은 「12개월 환산」 하나다.** 자리마다 다른 낱말을 만들지 않는다.
    **꼴을 고를 일이 생기면 짧은 쪽으로 가고 그 사실을 적는다.**
  · **기간 값 자리에 「12개월 환산」 을 붙이지 않는다** — 그 반대도 같다.
    한 이름이 두 자리에서 다른 것을 가리키게 되면 **그 자리에서 멈춘다.**
  · **새 안내를 붙이기 전에 이름을 고쳐 해결되는지 먼저 본다.**
    화면 문구를 늘리지 않는다. 예산은 `tools\screen_budget.py` 가 쥔다.
    **넘으면 멈춘다.**
  · **배경·근거·제도 설명은 매뉴얼로 보낸다.** 그 벌에서 참인 말만 남긴다.
  · **화면 감사 네 수가 갈리면 자리마다 글자까지 적는다.** 수만 적지
    않는다. **2절이 적은 자리 밖에서 갈리면 멈춘다.**
  · **「멈춘다」 가 서면 반드시 멈춘다.** 멈춘 자리와 안 멈춘 자리를
    대조표에 각각 한 줄로. 멈출 일이 없었으면 없었다고 적는다.
  · **원인을 미리 적지 않았다.** 앞 판 보고의 수(383 · 365 · 243 · 57 ·
    확인 안 한 못 53 · 여유 2,428자)는 전부 **다시 잴 것**이다. 줄 번호와
    이름은 지금 파일에서 다시 찾는다.
  · **실물을 본다.** 소스 리터럴로 판정하지 않는다 — 화면은 png 를 함께
    보고(DOM 텍스트를 실물로 읽지 않는다), PPT·Excel·Word 는 떠서 본다.
  · 되돌려 확인은 스크래치 monkeypatch · plugin 으로 한다. **얕은
    되돌림을 조심한다** — 갈아 끼움이 어느 길에 닿는지 먼저 값으로 낸다.
    더 돌렸으면 `git checkout HEAD -- 경로` 로 되돌린다.
  · **git stash 를 쓰지 않는다. S140 스태시를 지우지 않는다.**
  · **heredoc 을 쓰지 않는다 — 빈 호출도 안 된다.** 앞 판이 둘을 썼다.
    **스크래치는 편집 도구로 짓는다. `python -c` 를 쓰지 않는다** —
    0-1 의 `os.cpu_count()` 도 스크래치 `.py` 로 뜬다.
    **재는 것 · 세는 것 · 긴 출력 자르기는 도구로 한다** —
    `tools\run_tool.py` 의 `--tail` · `tools\pytest_counts.py` ·
    `tools\deck_words.py --snap/--read/--diff`(**온 경로로 적는다 —
    `.py` 를 직접 주면 WinError 193 이 난다**). **`run_tool` 출력을
    파이프로 다시 자르지 않는다.** 커밋 메시지는 스크래치 `.txt` 에 써서
    `git commit -F` 로 단다.
  · **긴 전수 출력은 처음부터 꼴로 묶어 낸다** — 앞 판이 4,169자리를
    통째로 내 91KB 를 만들고 다음 판에 20KB 로 줄였다.
  · **덱 19벌 뜨기는 많아야 두 판, 전체 pytest 는 한 판이다.**
    **첫 판에 `--durations=0` 을 붙인다.** 더 돌려야 하면 왜인지 값으로.
    **파일 수정은 편집 도구로 한다.** 앱을 띄우면 포트를 적고 내린 뒤
    닫힌 것을 확인한다. **벽시계를 절마다 잰다.**
