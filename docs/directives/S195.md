세우는 판이다. **고치는 판이 아니다** — 벌이 서자마자 어긋남이 보여도
이 판에서 안 고친다. 이름으로 올리고 사람이 다음 판에 정한다.
세션 도중 사람에게 묻지 않는다.

이 판의 못 박힌 안전한 쪽 열.
  · 계산을 안 고친다 — tariff\ · measures\ · diagnose\ · pv\ · compare\ ·
    ui\cache.py 가 0줄이다. 세우는 것은 벌을 적는 자리뿐이다.
  · 기존 케이스 열하나의 판정 160 이 하나라도 갈리면 그 자리에서 멈추고
    되돌린 뒤 값만 낸다. 회귀값 여덟도 같다. 기대값을 갱신하지 않는다.
    새 벌이 내는 판정은 갱신이 아니라 새로 적는 것이다 — 구별해 적는다.
  · 화면 문구를 안 건드린다. 감사 네 수가 갈리면 멈추고 값을 낸다.
  · **좌표를 새로 만들지 않는다** — 기상 취득 0회를 유지한다. 새 좌표가
    필요한 벌은 이 판에서 안 세우고 까닭을 적는다.
  · 못 열여덟 가운데 이 벌로 설 수 있게 된 것이 보여도 **이 판에서 못을
    안 박는다.** 설 수 있다는 것만 값으로 내고 이름으로 올린다.
    이 판이 박는 못은 4절 하나뿐이다.
  · **벌을 세우다 조건이 서로 배타인 것이 나오면 벌을 쪼개지 않는다** —
    멈추고 무엇과 무엇이 배타인지 값으로 낸다. 몇 벌로 나눌지는 사람이 정한다.
  · 되돌려 확인은 src\ 를 고치지 말고 스크래치 monkeypatch · plugin 으로
    한다. 부득이 돌렸으면 git checkout HEAD -- 경로 로 되돌리고
    git status 를 본다.
  · **백그라운드로 보내기 전에 예상 소요를 말한다. 모르면 모른다고 적는다.**
    상한을 걸고, 넘기면 스스로 멈추고 보고한다. 대기 루프를 만들지 않는다.
    S194 가 스크래치 무한 루프로 세 판을 죽였다 — 뒤로 보낸 까닭이
    「오래 걸릴 것 같아서」 였고 예상 소요를 안 적었다.
  · **스크래치는 %TEMP% 라 저장소 밖이다.** 저장소를 찾아 올라가는 고리를
    쓰지 않는다. 경로는 인자로 받거나 절대경로로 적는다.
  · 파일 수정도 재는 스크립트도 셸에 태우지 않는다. 스크래치 .py 로 만들어
    .venv\Scripts\python.exe 로 돌린다.

1절 — 조건 넷이 지금 어디서 서는지 전수로 재고, 한 벌에 설 수 있는지 본다

1-1  조건 넷을 값으로 고정한다 — 역률 100 · 잉여 있음 · 조합에 0원 수단 ·
