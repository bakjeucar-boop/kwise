  · **git stash 를 쓰지 않는다. S140 스태시를 지우지 않는다.**

    파일을 인자로. **도구로 되는 자리에 파이프를 쓰지 않는다.** 썼으면 쓴
    자리마다 「무엇을 보려고 · 왜 도구로 못 했나」. 커밋 메시지는 편집 도구로
    지은 `.txt` 로 `git commit -F`.
  · 미해결은 이름으로 떠 읽는다 — 칸을 통째로 흘리지 않는다. **벽시계를
