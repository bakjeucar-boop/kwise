S198 — 역률의 출발점을 원 부하 기준으로 맞추고, 그 정본을 문서에 앉힌다

고치는 판이고 **고치는 것은 하나다** — 역률 몫을 재는 밑이다.
S197 이 「태양광 전 역률의 출발점」 을 정한 문서가 여섯 문서에 0곳임을
값으로 냈고(1-3 ㄷ), **사람이 원 부하 기준으로 정했다.**

  정본 — **역률 개선의 절감액은 원 부하 기준으로 잰다.**
  곧 태양광이 기본요금을 낮추기 전의 기본요금을 밑으로 쓴다.

세션 도중 사람에게 묻지 않는다.

이 판의 못 박힌 안전한 쪽 열둘.
  · **고칠 자리가 하나를 넘으면 멈추고 값만 낸다.** 같은 병이라 함께
    고쳐야 한다고 보이면 **고치기 전에 같은 병인 것을 값으로 먼저 낸다.**
  · 계산 폴더 가운데 **measures\ 한 자리만** 닿을 수 있다.
    tariff\ · diagnose\ · pv\ 는 0줄이다. 넘으면 멈춘다.
  · **이 판은 금액이 움직인다.** 아래 셋 중 하나면 그 자리에서 멈추고
    되돌린 뒤 값을 낸다.
      ㄱ 2단계 역률 개선 카드의 금액이 움직이는 것
        (2단계는 독립 평가라 원 부하 기준이 이미 그 자리의 기준이다)
      ㄴ 케이스 회귀값 여덟이 움직이는 것
      ㄷ 조합에 역률이 **안 든** 벌의 금액이 움직이는 것
    기대값을 갱신하지 않는다 — 새 값은 xfail 못으로 남긴다.
  · **움직일 값의 크기나 방향을 미리 적지 않았다.** 값으로 낸다.
    앞 판 보고의 수도 다시 잰다 — 이차 자료다.
  · 화면 문구를 안 건드린다. 감사 네 수가 갈리면 멈추고 값을 낸다.
  · **문서에 정본을 적는 것은 이 판의 일이다**(3절). 다만 적는 자리는
    하나이고, 다른 문서는 그 자리를 가리키게만 한다.
  · 못이 소스 글자나 식을 다시 적으면 안 된다 — 실물에 뜬 값을 본다.
  · 되돌려 확인은 src\ 를 고치지 말고 스크래치 monkeypatch · plugin 으로
    한다. **얕은 되돌림을 조심한다** — S197 이 power_factor_pct 를
    enabled 와 함께 안 보내 조각이 안 섰고, 못이 안 문 것처럼 보였다.
    되돌림이 실제로 그 조각을 세웠는지 값으로 먼저 확인한다.
  · 부득이 src\ 를 돌렸으면 git checkout HEAD -- 경로 로 되돌리고
    git status 를 본다.
  · 셸에 문자열을 태우지 않는다. 파일 수정도, 재는 스크립트도, 한 줄짜리
    확인도 전부 스크래치 .py 로 만들어 .venv\Scripts\python.exe 로 돌린다.
    셸에는 파일 이름만 싣는다. 스크래치는 %TEMP% 라 저장소 밖이다 —
    저장소를 찾아 올라가는 고리를 쓰지 않는다.
  · 백그라운드로 보내기 전에 예상 소요를 말한다. 모르면 모른다고 적는다.
    상한을 걸고, 넘기면 스스로 멈추고 보고한다. 대기 루프를 만들지 않는다.
  · 앱을 띄운 채 끝내지 않는다. 케이스 결과 xlsx 는 저장소 판을 먼저 뜬
    뒤에 돌린다(같은 날 덮인다).
