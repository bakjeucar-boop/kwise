    회귀값 여덟도 같다. 기대값을 갱신하지 않는다.
  · 화면 문구를 안 건드린다 — 이 판은 화면 자리가 없다. 감사 네 수가
    갈리면 멈추고 값을 낸다.
  · 1절이 찾은 뿌리를 고치는 것이 문서 세 수 가운데 둘 이상을 움직이면
    멈추고 값을 낸다. 어느 수가 정본인지는 사람이 다음 판에 정한다.
  · 3절에서 안 빨개지는 못이 있으면 그 사실과 까닭을 값으로 적고
    고치지 않는다 — 이름으로 올린다.
  · 되돌려 확인은 src\ 를 고치지 말고 스크래치 monkeypatch · plugin 으로
    한다. 부득이 돌렸으면 git checkout HEAD -- 경로 로 되돌리고
    git status 를 본다.
  · 파일 수정도 재는 스크립트도 셸에 태우지 않는다. 스크래치 .py 로 만들어
    .venv\Scripts\python.exe 로 돌린다.

원인·전제를 미리 적지 않았다. 앞 판 보고의 수는 값이 아니라 다시 잴 것으로
