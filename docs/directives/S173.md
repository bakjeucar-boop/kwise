# S173 — 마무리 판 (기록·문서만 · 코드 무접촉)

## 서문 — 이 판이 지키는 것

1. **코드 무접촉이다.** `src\` · `tests\` · `data\` · `tools\` 를 한 줄도
   안 고친다. 이 판이 고치는 것은 기록과 문서뿐이다 — `PROCEED.md` ·
   `docs\OPEN_ITEMS.md` · `docs\HANDOVER.md` · `CLAUDE.md` ·
   `docs\directives\S173.md`. 그 밖의 파일이 움직이면 그것은 결함이다.

2. **pytest 전체를 돌리지 않는다.** 이 PC(2번)는 갈래 넷 합이 17분을 넘는다.
   돌리는 것은 **문서 못**뿐이다 (4절).

3. **애매한 것은 고치기 전에 이력으로 갈라낸다.** 아래 1·2절이 전부 그것이다 —
   `git log` · `git show` · 기존 로그 파일에서 값을 뜬다. **짐작해 채우지
   않는다.** 안 갈리면 「안 갈렸다」 로 적는다.

4. **중간에 묻지 않는다.** 갈릴 자리에 안전한 쪽이 박혀 있다. 그래도 걸리면
   **안 고치고 이름만 올리고** 값을 보고에 낸다.

5. **파일 수정은 편집 도구로만.** 셸에 문자열을 실어 고치지 않는다 —
   heredoc · echo · printf · sed · awk 전부. 재는 스크립트도 스크래치 `.py` 로
   만들어 `.venv\Scripts\python.exe` 로 돌린다.

6. **절마다 커밋한다.** 메시지는 스크래치 파일로 쓰고 `git commit -F 파일` 로
   건다 (이 셸에서 `git commit -F -` 는 여러 줄이 안 먹는다).

7. **이 지시서를 `docs\directives\S173.md` 에 받은 본문 그대로 앉힌다** (4절).

## 마지막에 낼 것 여덟

이 밖의 서술을 덧붙이지 않는다. 마지막에 한 번만 보고한다.
표의 결과 칸은 30자 안쪽으로 쓴다.

1. **대조표** — 절·항마다 한 줄. 결과는 수치나 판정으로.
2. **만든/바꾼 파일** — +/− 줄 수. **건드리지 않은 파일도 한 줄로** —
   `src\` · `tests\` · `data\` · `tools\` 가 0 인지 명시한다.
3. **수치가 움직인 곳** — 종전/지금. 미해결 · 갈래 · 문서 못 건수 ·
   갈래별 소요. 없으면 「없음」.
4. **판단한 것** — 스스로 고른 갈래와 그 근거. 1-3 의 닫기/이름 갈기 판정과
   1-2 의 「계산에 닿나」 판정을 여기 적는다.
5. **돌린 것 / 안 돌린 것** — 값과 오염 여부. **PC 와 「깨끗한 판인가」 를
   함께.** 안 돌린 것은 왜.
6. **예상과 달랐던 것** — 없으면 「없음」. 안 갈린 것은 「안 갈렸다」 로.
7. **프로젝트 지식 재업로드** — `CLAUDE.md` · `collaboration.md` ·
   `project-overview.md` 셋 중 이 판에 고친 것. 셋 밖은 적지 않는다.
8. **박은 못 · 걷은 못 · 되돌려 확인한 못** — 이름으로. 확인 안 한 못은
   확인 안 했다고 적는다. 없으면 「없음」.

`ctx` 는 셋 — 세션 예산 <종전> → <지금> (약 <차이>) · 가장 크게 먹은 것
하나 · 줄일 수 있었다고 보는 것 하나.
