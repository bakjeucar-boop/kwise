S186 — 오늘 움직인 금액이 실물 넷에 어떻게 그려지는지 눈으로 보고 닫는다

이 판은 마무리 판이다. 코드를 고치지 않는다 — src\ 0줄이 목표다.
오늘 S185 가 조합 절감액을 1,479만원 움직였는데 실물을 안 봤다. 그 자리를
눈으로 보고, 못 몇을 되돌려 확인하고, 기록을 닫는다.

이 판의 못 박힌 안전한 쪽 여섯.
  · src\ · data\ · tools\ 를 한 줄도 안 고친다. 실물에서 어긋난 것이 나오면
    **안 고치고 값과 화면 글자를 그대로 보고에 낸다.**
  · 화면 문구를 늘리지 않는다.
  · 되돌려 확인은 src\ 를 고치지 말고 스크래치 monkeypatch 로 한다.
    부득이 파일을 돌렸으면 git checkout HEAD -- 경로 로 되돌리고 git status 를
    본다.
  · 새 미해결을 올리기 전에 「계산·화면·PPT·Excel 에 닿는가」 를 본다.
    안 닿으면 이름만 올리고 보고에서 길게 적지 않는다.
  · 앱을 띄웠으면 내리고 포트가 닫혔는지 확인한다.
  · 파일 수정도 재는 스크립트도 셸에 태우지 않는다. 스크래치 .py 로 만들어
    .venv\Scripts\python.exe 로 돌린다.

원인·전제를 미리 적지 않았다. 앞 판 보고의 수는 값이 아니라 다시 잴 것으로
다룬다 — 줄 번호와 이름은 지금 파일에서 다시 찾는다.


0절 — 판 열기

0-1  어느 PC 인지. os.cpu_count() · RAM · -n auto 가 고른 일꾼 수.
0-2  git pull. HEAD 와 origin 이 같은지, 워크트리가 깨끗한지.

0-5  기상 캐시에 용인 벌이 있는지 본다. 없으면 케이스 스터디를 먼저 돌린다.

커밋하지 않는다.


1절 — 목표가 움직인 벌 셋의 실물 넷을 연다

S185 가 조합 목표와 몫을 세 벌에서 움직였다. 그 수가 **실물에 어떻게 그려지는지**
값과 글자로 본다. **고치지 않는다.**

1-1  목표가 움직인 벌 셋을 지금 값으로 다시 찾아 이름과 새 목표·몫을 적는다.
     앞 판 보고의 수를 그대로 옮기지 않는다.
1-2  벌마다 덱을 뽑는다.

         .venv\Scripts\python.exe tools\render_deck.py --case <벌> --png

     계약전력 목표와 조합 절감액이 선 장을 찾아 **글자를 그대로 옮겨 적는다.**
     장 번호 · 적힌 수 · 곁 문구.
1-3  같은 벌의 **Excel 과 Word** 를 뽑아 조합 절감액과 계약전력 목표가 선
     자리를 찾아 **글자와 수를 그대로 옮겨 적는다.** S185 가 안 본 자리다.
1-4  **화면**을 연다. 같은 조건으로 3단계를 띄워 계약전력 목표와 「조합 시
     추가 절감」 금액을 찍는다.

         .venv\Scripts\python.exe tools\capture_screen.py --spot <조합이 보이는 자리>

     캡처가 접힘을 못 펴면 그 사실을 적는다 — 도구는 고치지 않는다.
1-5  **넷(화면 · PPT · Excel · Word)이 같은 수를 적는지** 벌마다 표로 맞댄다.
     어긋나는 칸이 있으면 **이름 · 수 · 글자**를 그대로 낸다. **고치지 않는다** —
     미해결에 이름으로 올린다.
1-6  1-5 에서 어긋남이 0 이면 그 사실을 적는다. 억지로 찾지 않는다.

6절 — 보고

마지막에 한 번만 보고한다. 중간 보고를 내지 않는다. 정확히 여덟 항목이고
그 밖의 서술을 덧붙이지 않는다. 표 칸은 30자 안쪽으로 쓴다.

  1 대조표 — 절·항마다 한 줄. 결과는 수치나 판정으로.
  2 만든/바꾼 파일 — 파일마다 +/− 줄 수. **src\ · data\ · tools\ 가 0줄인
    것을 명시한다.** 건드리지 않은 것도 한 줄.
  3 수치가 움직인 곳 — 종전/지금 표. 없으면 「없음」.
  4 판단한 것 — 스스로 고른 갈래와 그 근거. 특히 2-2 에서 어느 여섯을 골랐나.
  5 돌린 것 / 안 돌린 것 — 안 돌린 것은 까닭.
  6 예상과 달랐던 것 — 없으면 없음. **1절 실물에서 어긋난 것이 있으면 여기와
    3번에 함께 낸다.**
  7 프로젝트 지식 재업로드 — CLAUDE.md · collaboration.md ·
    project-overview.md 셋 중 오늘 하루에 고친 것. 없으면 없음.
  8 박은 못 · 되돌려 확인한 못 — 이름으로. 못마다 「어디를 어떻게 틀렸더니
    빨개졌나」 한 줄. 확인 안 한 못은 「이번 판에 확인 안 함」 과 「한 번도
    확인 안 함」 을 갈라 적고 세 판 이상 지난 수도 적는다.

ctx 칸을 셋으로 적는다 — 세션 예산 종전 → 지금(약 차이) · 가장 크게 먹은 것
하나 · 줄일 수 있었다고 보는 것 하나.

마지막 한 줄로 돌고 있는 백그라운드 셸이 없는지 확인한 결과와 **push 가
끝났는지**를 적는다.
