S199 — 정본이 남긴 xfail 셋을 값으로 가르고, 낡은 기대값만 정본에 맞춘다

고치는 판이고 **고치는 것은 tests\ 뿐이다** — src\ 가 0줄이다.
S198 에 사람이 정본을 정했고(역률 개선의 절감액은 원 부하 기준으로 잰다 ·
docs\REQUIREMENTS_kwise.md 8.1) 그 판이 기대값을 안 갱신하고 xfail 로
남겼다. 이 판이 그것을 가른다.
세션 도중 사람에게 묻지 않는다.

이 판의 못 박힌 안전한 쪽 열둘.
  · **src\ 가 0줄이다.** 계산도 화면도 안 고친다. 고쳐야 닫히는 것이
    보여도 이름으로 올린다. **울타리는 폴더가 아니라 자리 수다** — 이 판이
    고치는 자리는 **xfail 이 붙은 시험뿐**이고, 그 밖의 시험을 고쳐야 하면
    멈추고 값만 낸다.
  · **낡았는지 값으로 먼저 가른다.** xfail 이 붙어 있다는 것만으로 기대값을
    갈지 않는다 — 갈래마다 「정본이 무엇을 요구하나 · 지금 기대값이 무엇을
    적나 · 둘이 어떻게 다른가」 를 값으로 낸 뒤에 고친다.
  · **걷는 조건이 서서 선 못은 안 건드린다** — 그것은 기대값이 낡은 것이
    아니라 제 일을 하는 못이다. 어느 쪽인지 1절이 가른다.
  · 금액이 한 원이라도 움직이면 그 자리에서 멈추고 되돌린 뒤 값을 낸다.
    회귀값 여덟 · 케이스 판정 174 · 감사 네 수도 같다. **이 판은 시험만
    고치므로 금액이 움직일 까닭이 없다** — 움직이면 무언가 틀린 것이다.
  · 못이 소스 글자나 식을 다시 적으면 안 된다 — 실물에 뜬 값을 본다.
  · 되돌려 확인은 src\ 를 고치지 말고 스크래치 monkeypatch · plugin 으로
    한다. **얕은 되돌림을 조심한다** — 되돌림이 실제로 그 조각을 세웠는지
    값으로 먼저 확인한다(S197 6항 · S198 8항).
  · 부득이 src\ 를 돌렸으면 git checkout HEAD -- 경로 로 되돌리고
    git status 를 본다.
  · **git stash 를 쓰지 않는다** — S198 이 이미 커밋된 경로에 stash push 를
    했다가 S140 의 옛 스태시를 pop 으로 꺼내 충돌했다. 되돌림은
    git checkout HEAD -- 로만 한다. **그 스태시를 지우지 않는다.**
  · 셸에 문자열을 태우지 않는다. 파일 수정도, 재는 스크립트도, 한 줄짜리
    확인도 전부 스크래치 .py 로 만들어 .venv\Scripts\python.exe 로 돌린다.
    셸에는 파일 이름만 싣는다. 스크래치는 %TEMP% 라 저장소 밖이다 —
    저장소를 찾아 올라가는 고리를 쓰지 않는다.
  · 백그라운드로 보내기 전에 예상 소요를 말한다. 모르면 모른다고 적는다.
    상한을 걸고, 넘기면 스스로 멈추고 보고한다. 대기 루프를 만들지 않는다.
  · 앱을 띄운 채 끝내지 않는다. 케이스 결과 xlsx 는 저장소 판을 먼저 뜬

       ㄴ **걷는 조건이 서 있다** — 무엇이 서 있나. 이 판이 안 건드린다
       ㄷ **못 가른다** — 무엇이 더 있어야 갈리는지

     내고 이 판에서 안 고친다** — 기대값 하나만 고친다.
1-4  **정본이 요구하는 값을 실물에서 뜬다** — 시험이 쓰는 그 벌을 실제로
     돌려 지금 코드가 내는 값을 낸다. 기대값을 머리로 고쳐 쓰지 않는다.
