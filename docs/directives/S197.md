S197 — 단순 합과 합산효과가 25,055.99원 갈리는 자리를 닫는다

고치는 판이고 **고치는 것은 하나다** — 조합에서 여지 없는 수단을
단순 합은 담고 합산효과는 빼는 자리다(S196 2-4 · 3-2).
세션 도중 사람에게 묻지 않는다.

이 판의 못 박힌 안전한 쪽 열둘.
  · **정본은 문서가 정한다.** 어느 쪽이 옳은 합인지 사람이 안 정했다 —
    요구사항서 · CLAUDE.md · project-overview.md 에서 값으로 찾는다.
    **셋이 갈리거나 어디에도 없으면 그 자리에서 멈추고 고치지 않는다.**
    갈린 값을 전수로 내고 이름으로 올린다.
  · **고칠 자리가 하나를 넘으면 멈추고 값만 낸다.** 넘겨야 닫히는 것이
    보여도 고치지 말고 이름으로 올린다. 같은 병이라 함께 고쳐야 한다고
    보이면 **고치기 전에 같은 병인 것을 값으로 먼저 낸다**(S194 가
    셋을 함께 고쳤고 까닭은 나중에 적혔다).
  · 계산을 안 고친다 — tariff\ · measures\ · diagnose\ · pv\ 가 0줄이다.
    고치는 것은 조합을 모으는 자리뿐이다.
  · **이 판은 금액이 움직인다.** 움직이는 것이 이 판의 일이므로 멈추는
    잣대를 따로 둔다 — 아래 셋 중 하나면 그 자리에서 멈추고 되돌린다.
      ㄱ 2단계 수단 카드의 금액이 움직이는 것
      ㄴ 케이스 회귀값 여덟이 움직이는 것
      ㄷ 조합에 여지 없는 수단이 **안 든** 벌의 금액이 움직이는 것
    기대값을 갱신하지 않는다 — 새 값은 xfail 못으로 남긴다.
  · 화면 문구를 안 건드린다. 감사 네 수가 갈리면 멈추고 값을 낸다.
    **단순 합 자리의 이름과 뜻을 이 판에서 정하지 않는다** — 값이 맞으면
    이름은 그대로 두고, 이름이 뜻과 어긋나 보이면 이름으로 올린다.
  · S196 이 박은 못 test_여지_없는_수단을_2단계는_빼고_3단계_조합은_담는다
    은 **지금 어긋남을 무는 못**이다. 고치면 빨개진다 — 그것이 옳다.
    **그 못을 지운다**(사실이 뒤집혔으므로 남길 것이 없다). 지운 자리에
    까닭을 적고 **새 사실을 값으로 보는 못**으로 옮긴다.
  · 못이 소스 글자나 식을 다시 적으면 안 된다 — 실물에 뜬 값을 본다.
  · 되돌려 확인은 src\ 를 고치지 말고 스크래치 monkeypatch · plugin 으로
    한다. 부득이 돌렸으면 git checkout HEAD -- 경로 로 되돌리고
    git status 를 본다.
  · 셸에 문자열을 태우지 않는다. 파일 수정도, 재는 스크립트도, 한 줄짜리
    확인도 전부 스크래치 .py 로 만들어 .venv\Scripts\python.exe 로 돌린다.
    셸에는 파일 이름만 싣는다. S196 이 이 자리를 지켰다.
  · 스크래치는 %TEMP% 라 저장소 밖이다. 저장소를 찾아 올라가는 고리를
    쓰지 않는다. 경로는 인자로 받거나 절대경로로 적는다.
  · 백그라운드로 보내기 전에 예상 소요를 말한다. 모르면 모른다고 적는다.
    상한을 걸고, 넘기면 스스로 멈추고 보고한다. 대기 루프를 만들지 않는다.
  · 앱을 띄운 채 끝내지 않는다. 띄웠으면 내리고 포트가 닫혔는지 본다.
    케이스 결과 xlsx 는 저장소 판을 먼저 뜬 뒤에 돌린다(같은 날 덮인다).
