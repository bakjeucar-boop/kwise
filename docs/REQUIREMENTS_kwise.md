# kWise 요구사항서

건물 전력 비용 진단 및 개선안 비교
문서 버전 1.0 · 2026-08-06

---

## 1. 개요

### 1.1 목적

**운영 중 건물의 15분 실측 전력 데이터로 전력 비용 구조를 진단하고,
요금제 전환·계약 조정·태양광·ESS 등 개선 수단의 효과를 같은 기준으로 비교한다.**

태양광은 여러 개선 수단 중 하나다. 설비 투자 없이 요금제와 계약만 조정해도
상당한 절감이 나오는 경우가 많으며, 그 판정이 이 도구의 첫 산출물이다.

### 1.2 세 계층

| 계층 | 질문 | 산출 |
|---|---|---|
| **진단** | 지금 어떻게 쓰고 얼마 내고 있나 | 부하 패턴, 요금 구조, 계약 적정성, 피크 특성 |
| **개선** | 무엇을 하면 얼마가 줄어드나 | 수단별 절감액·투자비·회수기간 |
| **비교** | 어느 조합이 최선인가 | 같은 기준의 나란한 비교, 확실성 등급 |

### 1.3 이 도구가 푸는 문제

손계산으로 답할 수 없는 것에 집중한다.

| 문제 | 왜 손계산이 불가능한가 |
|---|---|
| 최적 선택요금 판정 | 시간대별 사용량 분포가 필요하고, 설비 도입 후 그 분포가 바뀜 |
| 계약전력 적정성 | 15분 최대수요 이력 전체가 필요 |
| 기본요금 절감 가능 여부 | 연중 어느 15분이 최대인지, 그 순간 발전량이 얼마인지 시계열 없이 알 수 없음 |
| ESS 최소 용량 | 목표 피크를 지키는 출력·용량은 디스패치 시뮬레이션이 필요 |
| 잉여 발생량과 시간대 분포 | 시계열 필요 |

연간 발전량, 자가소비율, 전력량요금 절감의 개략치는 엑셀로도 나온다.
**이 도구의 존재 이유는 위 다섯 가지다.**

### 1.4 대상 사용자

사내 설계·영업 담당자. 발주처 제안 및 초기 검토 단계에서 근거 있는 답변을 만드는 것이 목적이다.

### 1.5 범위 밖

- **신축 건물 부하 예측** — 실측 데이터가 없는 건물. 별도 프로젝트로 계획
- 건물 에너지 시뮬레이션 — 실측 부하를 쓰므로 불필요
- ZEB·건축물에너지효율등급 등 **인증용 산출**
- 기후환경요금, 연료비조정요금, 부가가치세, 전력산업기반기금
- 역률요금 (추정값 기반 참고 산출만)
- 계통연계 기술 검토, 보호협조
- 상계거래·외부 신재생에너지 구매의 **자격요건 판정** (금액만 참고 제시)

## 2. 실행 환경

상세는 `docs/ENVIRONMENT.md` (Windows 11) 를 따른다. 핵심만 옮긴다.

| 제약 | 대응 |
|---|---|
| Windows 기본 인코딩이 cp949 | `PYTHONUTF8=1` 등록, 파일 열 때 `encoding=` 명시 |
| pvlib은 tz-aware 인덱스 생성 | **Excel 출력 직전 `dt.tz_localize(None)`** — 누락 시 `ValueError` |
| Excel 파일 잠금 | 결과 파일명에 날짜·시각 접미사, 저장 실패 시 안내 |
| 한글 폰트 | 맑은 고딕 내장. matplotlib 사용 시 `font.family = "Malgun Gothic"` |
| 경로 | `pathlib.Path` 만 사용. 문자열 결합·구분자 하드코딩 금지 |
| 메모리 | 여유가 있어도 다중 시나리오를 한 번에 올리지 않는다. 순차 처리 |
| 가상환경 | 프로젝트 내 `.venv`, `pip install -e .` |

**배포** — 1단계는 Streamlit 웹 UI(로컬 실행). 발주처 사용량 데이터를 다루므로
로컬·사내망을 기본으로 하고, 업로드 데이터는 서버에 영구 저장하지 않는다.
단독 실행 exe 전환은 향후 별도 검토한다.

### 2.1 패키지 구조

```
src/kwise/
├── io/         사용량 데이터 로더
├── quality/    품질 검사, 정전 검출
├── tariff/     요금 엔진, 시간대 분류
├── pv/         태양광 계산, 기상 취득
├── diagnose/   진단 — 부하 패턴, 피크 특성, 계약 적정성
├── measures/   개선 수단 평가 — 요금제, 계약, PV, ESS, 잉여
├── compare/    조합 비교
├── report/     Excel 출력, CLI 배치
└── ui/         Streamlit 화면
```

의존 방향은 위에서 아래로만 흐른다. `ui` 는 계산 로직을 담지 않고 순수 함수를 호출만 한다.

## 3. 입력 사양

### 3.1 사용량 데이터 (필수)

한전 사이버지점에서 내려받는 CSV 형식을 기본으로 한다.

```
검침일,순방향 유효전력량(KWH)
2023-04-25 00:15,321.84
```

| 항목 | 요구 |
|---|---|
| 인코딩 | utf-8-sig, cp949, euc-kr, utf-8 순차 시도. 컬럼 매칭 성공까지 확인해야 채택 |
| `24:00` 표기 | 다음 날 `00:00` 으로 변환 |
| 파일 형식 | csv, xls, xlsx |
| 시간 간격 | 15분·1시간 자동 인식. 1시간 데이터는 기본요금 판정에 한계가 있음을 경고 |
| 컬럼명 | 후보 목록 기반 유연 매칭 |
| 기간 | 역년이 아닌 임의 기간 허용 |
| 그리드 위상 | 최빈값으로 판정 |
| **라벨 규약** | **검침일 라벨은 구간 끝이다.** 하루가 `00:15` 로 시작해 `24:00` 으로 끝나 96행이 된다. 계절·시간대·월 귀속은 라벨에서 한 구간을 뺀 시각으로 판정한다. `15:00` 슬롯은 `14:45~15:00` 사용량이므로 중간부하이며, 첫 최대부하 슬롯은 `15:15` 이다. **PV 시계열을 붙일 때 같은 규약을 적용해야 15분 어긋나지 않는다.** |

### 3.2 계약 정보 (필수)

**진단 단계에서 필요한 유일한 입력이다.** 설비 정보는 이 단계에서 묻지 않는다.

| 항목 | 입력 방식 | 비고 |
|---|---|---|
| 계약종별 | 사용자 직접 선택 | 데이터로 추정 불가 |
| 계약전력 (kW) | 사용자 입력 | 청구서 기재값. 적정성 진단의 전제 |
| 전압구분 | 선택 | 계약전력으로 후보 제시 |
| 선택요금 | 선택 | 추정치 제시, 어차피 전 조합 계산 |
| 역률 (%) | 입력, 기본값 92 | 추정값 사용 |

**추정 보조** — 업로드 직후 아래를 계산해 제시하고 사용자가 확정한다.

- 갑/을 구분 — 계약전력 임계값 (일반용·산업용 300 kW, 교육용 1,000 kW)
- 전압구분 후보 — 계약전력 규모 기반
- 연간 이용시간 = 연간 사용량 ÷ 최대수요 → 선택요금 후보
- 계약종별 힌트 — 부하율·주말 부하 비율·계절 패턴으로 성격 추정 (확정 아님)

### 3.3 개선 수단별 입력

**2단계에서 해당 수단을 켤 때만 묻는다.** 진단만 볼 사용자는 아무것도 입력하지 않는다.

**태양광**

| 항목 | 기본값 |
|---|---|
| 설치 용량 (kWp) | — (용량 곡선 모드에서는 범위) |
| 방위각 / 경사각 | 180° / 30°, 다중 어레이 허용 |
| 옥상 면적 (m²) / 가용 비율 | — / 60% |
| GCR (이격거리비) | 0.4 |
| 시스템 손실 | 14% |
| 벽면 PV 적용 | 선택 (경사각 90°) |
| 위치 | 좌표 |

**ESS**

| 항목 | 기본값 |
|---|---|
| 출력 (kW) / 용량 (kWh) | — (역산 모드에서는 출력) |
| 왕복효율 / DoD | 88% / 90% |
| 단가 (원/kWh) | 사용자 입력 |

## 4. 데이터 품질 검사

업로드 직후 요약을 표시한다. **조용히 넘어가지 않는다.**

### 4.1 점검 항목

| 항목 | 판정 | 표시 |
|---|---|---|
| 기간 | 시작·종료·총 일수 | 12개월 미만이면 경고 |
| 결측 | 예상 행수 대비 누락 수·비율 | 3% 초과 시 경고 |
| 결측의 시간대 분포 | 피크 시간대(10~16시, 평일) 편중 여부 | 편중 시 **"최대수요 과소평가 위험"** |
| **최장 연속 결측 구간** | 가장 긴 연속 공백의 길이와 기간 | 1일 초과 시 경고 |
| **월별 결측률** | 월마다 개별 산출 | 5% 초과 월은 별도 표시 |
| **정전 구간** | 연속 결측 + 직전 부분 적산 행 + 복전 후 저부하 | 구간과 지속시간 |
| 이상치 | 0 kW, 계약전력 초과, 급변 | 건수 |
| 중복 시각 / 간격 일관성 | | 처리 방침 표시 |

**연속 공백은 편중과 다른 위험이다.** 편중 배수는 결측이 특정 시간대에 몰렸는지만 본다.
며칠짜리 연속 공백은 모든 시간대가 균등하게 빠지므로 배수가 1 근처가 되어 음성으로
판정되지만, 실제로는 그 달의 최대수요 판정 자체를 무의미하게 만든다.
편중 배수와 최장 연속 결측을 **모두** 산출한다.

**정전 구간은 결측과 구분한다.** 정전 중에는 피크가 발생할 수 없으므로 편중 판정에서
제외해야 정확하다. 계량기 통신 장애로 인한 결측은 실제 피크를 놓쳤을 수 있지만 정전은 아니다.
정전 판정은 **흔적 3종 중 연속 결측을 뺀 나머지 2개 이상**을 요구한다.
연속 결측은 모든 결측이 갖는 성질이라 근거가 되지 못한다.

편중 판정에서 정전 슬롯은 **분자·분모 양쪽에서** 뺀다. 한쪽만 빼면 비율이 왜곡된다.
제외한 값이 정본이고, 포함한 값은 비교용으로 함께 담는다.

### 4.2 결측 처리

- 기본: **보간하지 않는다.** 결측 구간은 계산에서 제외하고 그 사실을 명시한다.
- 최대수요는 관측된 값 중 최대이며, 결측 구간에 더 큰 값이 있었을 수 있음을 표기한다.
- 결측률 5% 초과 월은 요금 명세에 결측률을 병기하고 최대수요를 **"신뢰 제한"** 으로 표시한다.
- 선형보간 옵션을 두되 기본값은 미적용.

### 4.3 그리드 이탈 행

15분 그리드를 벗어난 행(부분 적산)은 아래처럼 처리한다.

| 용도 | 처리 | 이유 |
|---|---|---|
| kW 수요 산정 | **제외** | 위상이 달라 15분 평균 환산 시 수요가 왜곡됨 |
| kWh 사용량 합계 | **포함** | 실제 사용된 전력량. 한전 청구도 적산값 기준 |
| 결측 판정 | 별도 분류 | "결측"이 아니라 "부분 계량" |

## 5. 요금 엔진

### 5.1 계산 대상

**기본요금과 전력량요금만 계산한다.** 그 외 요금요소는 산출물에 미포함으로 안내한다.

> 본 결과는 기본요금과 전력량요금만 산출한 값입니다. 기후환경요금, 연료비조정요금,
> 부가가치세, 전력산업기반기금은 포함되지 않았습니다. 이들은 모두 사용전력량에
> 비례하므로 실제 절감액은 본 결과보다 다소 크게 나타납니다.

### 5.2 기본요금

```
기본요금(월) = 요금적용전력 × 종별·전압·선택요금별 기본요금 단가
```

**요금적용전력 규칙 (한전 기본공급약관 제68조)**

세 조건이 겹친다. 하나라도 빠뜨리면 결과가 크게 어긋난다.

**① 대상 시간대 — 경부하 제외**

일반용(을), 산업용(을), 교육용(을), 일반용(갑)Ⅱ, 산업용(갑)Ⅱ 는
**중간부하와 최대부하 시간대의 최대수요전력 중 큰 것**만 대상이다.
경부하 시간대(22:00~08:00)의 수요는 아무리 커도 요금적용전력이 되지 않는다.

공휴일은 최대수요전력을 경부하로 계량하므로 **공휴일 피크도 자동으로 제외**된다.

**② 대상 월 — 하계·동계 + 당월**

```
요금적용전력 = max( 7·8·9월, 12·1·2월, 검침 당월 )   ← 직전 12개월 범위 내
```

3~6월과 10~11월의 피크는 그 달의 당월분으로만 잡히고 이후 달로 이월되지 않는다.

> **주의 — "하계·동계"와 전력량요금의 "계절"은 다르다.**
>
> | | 대상 |
> |---|---|
> | 요금적용전력 대상월 | 7·8·9 · 12·1·2 |
> | 전력량요금 계절 | 여름 6·7·8 / 봄가을 3·4·5·**9**·10 / 겨울 **11**·12·1·2 |
>
> 9월은 전력량요금상 봄·가을철이지만 요금적용전력 대상월이다.
> 6월과 11월은 반대로 여름·겨울 단가를 쓰지만 대상월이 아니다.
> **같은 함수로 판정하지 말 것.**

**③ 하한 — 계약전력의 30%**

위 ①②로 구한 값이 계약전력의 30% 미만이면 계약전력의 30%를 적용한다.
교육용 등 일부 종별은 15%가 적용되는 특례가 있으므로 **종별 속성으로 둔다**
(`contract_floor_ratio`, 기본값 0.30).

**그 밖에**

- 최대수요전력 = 15분 평균 수요의 최대값
- 직전 이력이 없으면 첫 몇 달이 과소 산출된다. `prior_peaks=` 인자로 주입 가능하게 하고,
  주입되지 않으면 경고를 붙인다.
- 계약전력을 초과하면 초과사용부가금이 부과된다. 경부하 시간대 초과는 요금적용전력에
  영향을 주지 않지만 초과사용부가금 대상은 되므로 별도로 검사한다.

**이 규칙들이 결과에 미치는 영향**

- **봄·가을 피크 저감은 기본요금 절감 가치가 거의 없다.** 그런데 태양광 발전이
  가장 강한 계절이 봄·가을이다. PV 의 기본요금 기여는 7~9월에 집중되고
  12~2월에는 발전이 약하다. 이 비대칭을 산출물에 명시한다.
- **ESS 야간 충전이 만드는 피크는 기본요금 대상이 아니다.** 다만 계약전력 초과
  여부는 검사해야 한다.

### 5.3 전력량요금

**계절·시간대 구분** (제주 제외)

| 시간대 | 여름철(6~8월) | 봄·가을철(3~5월, 9~10월) | 겨울철(11~2월) |
|---|---|---|---|
| 경부하 | 22:00~08:00 | 22:00~08:00 | 22:00~08:00 |
| 중간부하 | 08:00~15:00, 21:00~22:00 | 08:00~15:00, 21:00~22:00 | 08:00~09:00, 12:00~16:00, 19:00~22:00 |
| 최대부하 | 15:00~21:00 | 15:00~21:00 | 09:00~12:00, 16:00~19:00 |

**요일 규칙** — `holidays` 라이브러리 사용

- 토요일: 최대부하 시간대의 사용전력량을 **중간부하 시간대로 계량**
- 공휴일: 최대수요전력 및 사용전력량을 **경부하 시간대로 계량**
- **일요일도 공휴일로 계량한다.** `holidays` 는 일요일을 담지 않으므로 직접 더한다.
  관공서 공휴일 규정에 일요일이 포함된다. 누락 시 연 52일이 최대부하로 잘못 계량된다.
  토글로 끌 수 있게 하고, 청구서 확보 시 이 항목을 가장 먼저 대조한다.
- **임시공휴일은 제외** → 사용자가 날짜를 추가·제외할 수 있는 입력을 둔다

### 5.4 결측이 있는 월의 처리

전력량요금은 사용량에 비례하므로 결측이 있는 월은 과소 계산된다.
기본요금은 최대값 기반이라 보정할 수 없다.

| 기준 | 방법 | 용도 |
|---|---|---|
| 관측 기준 | 있는 데이터 그대로 | 기본 표시값. 보수적 |
| 결측 보정 기준 | 월별 전력량요금을 `1 ÷ (1 − 결측률)` 로 환산 | 회수기간 산정 참고 |

어느 쪽을 썼는지 산출물에 반드시 표기한다. 도입 전후 차분(Δ)에는 같은 결측이
양쪽에 걸리므로 왜곡이 상대적으로 작다. **절대 금액보다 Δ 를 우선 신뢰한다.**

### 5.5 부분 월과 기간 표기

실무 데이터는 검침일 기준이라 역년이 아니다. 샘플은 2023-04-25 ~ 2024-04-27 로
월 버킷이 13개이며 앞뒤 두 개가 부분 월이다.

- **부분 월의 기본요금을 온전히 부과하지 않는다.** 두 조각을 합쳐 한 달로 처리하거나
  일수 비례로 안분한다. 어느 쪽을 썼는지 산출물에 표기한다.
- **결과를 "연간"으로 표시하지 않는다.** 실제 기간을 명시하거나 12개월로 환산한다.
- 12개월 미만 데이터는 환산 시 경고를 붙인다.

### 5.6 특례

- **산업용(을) 봄·가을철 주말 할인**: 토·일·공휴일 11:00~14:00 전력량요금 50% 할인.
  PV 최성기와 겹치므로 공장 사례에서 PV 절감 효과가 절반으로 깎인다. 미반영 시 과대평가된다.
- 종별별 시행일이 다르므로 요금 데이터에 시행일 필드를 둔다.

### 5.7 역률요금

무효전력 데이터가 없으므로 추정값 기반 참고 산출만 한다.

**PV 도입 시 역률 악화 경고를 구현한다.** 무효전력은 그대로인데 PV가 유효전력만 상쇄하므로
역률이 떨어진다. 추정 역률과 PV 용량으로 도입 후 예상 역률을 계산하고,
지상 90% 미만이면 콘덴서 조정 필요를 알린다.

### 5.8 추적성

산출물에 적용 근거를 표기한다.

```
적용 요금표: 2026-06-01 시행
계약종별: 일반용전력(을) 고압A 선택Ⅰ
기본요금 단가: 7,220 원/kW
계절·시간대 구분: 육지 기준
```

## 6. 진단

**설비 정보 없이, 업로드와 계약 정보만으로 나오는 결과다.**

### 6.1 부하 패턴

| 지표 | 의미 |
|---|---|
| 부하율 | 평균 ÷ 최대 |
| 기저부하 비율 | 야간 평균 ÷ 주간 평균 |
| 주말 부하 비율 | 주말 평균 ÷ 평일 평균 |
| 무인시간 부하 | 운영시간 외 사용량 |

기저부하가 과다하면 상시 가동 설비 점검 여지를 시사한다.

### 6.2 피크 특성

**단일 최대값이 아니라 월별 최대수요 12개를 산출한다.** 요금은 월별로 매겨지고,
요금적용전력은 그 이력의 최대치다.

| 산출 항목 |
|---|
| 월별 최대수요, 발생 시각 |
| 요금적용전력 |
| **연간 상위 100개 15분 구간의 시각·요일 분포** |
| 시간대별 평균 부하 프로파일 |

상위 구간의 시각 분포는 **태양광의 피크 기여 가능성을 즉시 보여주는 지표**다.
건물마다 정반대 결과가 나오므로 반드시 표시한다. 오전·정오 집중이면 PV 기여가 크고,
저녁·아침 집중이면 거의 없다.

### 6.3 현재 요금 구조

- 기본요금 대 전력량요금 비중
- 시간대별(경/중간/최대) 사용량 비중
- 계절별 사용량 비중
- 월별 요금 명세

### 6.4 계약전력 적정성

```
최대수요전력 ÷ 계약전력
```

계약전력 대비 최대수요가 낮으면 과계약이다. 하향 여지와 예상 절감액을 표시한다.
**PV와 무관하게 즉시 돈이 나오는 항목이다.**

단, 계약전력 하향은 되돌리기 어렵고 초과 시 위약금이 있으므로 **여유 확보 권고를 함께 표시한다.**

### 6.5 개선 여지 요약

## 7. 개선 수단 평가

**투자비 순으로 배치한다.** 사용자가 필요한 수단만 켠다.

### 7.1 선택요금 전환 (투자 0)

가능한 모든 선택요금 조합을 계산하여 표로 제시한다.

| 계약종별 | 선택요금 |
|---|---|
| 일반용(갑)Ⅰ, 산업용(갑), 교육용 | Ⅰ, Ⅱ |
| 일반용(을), 산업용(을) | Ⅰ, Ⅱ, Ⅲ |
| 일반용(갑)Ⅱ | Ⅰ, Ⅱ, Ⅲ, Ⅳ |

**두 기준을 모두 보여준다.**

1. 현행 선택요금 유지 기준
2. 최적 선택요금 전환 기준

설비 도입과 무관하게 선택요금 전환만으로 나오는 절감액을 별도 표시한다.
**설비 없이도 가치가 나오는 핵심 기능이다.**

선택지 목록은 요금 데이터 파일에서 생성한다. 하드코딩 금지.

### 7.2 계약전력 조정 (투자 0)

6.4 진단 결과를 근거로 목표 계약전력과 예상 절감액, 위약금 위험을 제시한다.

### 7.3 태양광

**발전량 산출**

- pvlib 기반, Open-Meteo 기상
- 다중 어레이 (지붕 + 벽면, 벽면은 경사각 90°)
- 어레이 상호 음영은 `pvlib.bifacial.infinite_sheds` 에 GCR 단일 파라미터 전달
- 기상 데이터는 `PROJECT_CACHE` 경로에 parquet 캐시

**용량 곡선** — 0부터 옥상 가용면적 상한까지 20단계로 변화시키며 표시한다.

- 자가소비율
- 기본요금 절감액 / 전력량요금 절감액
- 잉여 발전량
- 단순 회수기간

"태양광을 얼마나 넣어야 하나"가 실제로 가장 많이 받는 질문이다.

### 7.4 ESS

**목표 피크 역산** — 사용자가 목표 요금적용전력을 조정하면 아래를 산출한다.

| 산출 항목 | 의미 |
|---|---|
| 초과 구간 수 / 총 시간 | 몇 번, 몇 시간 |
| **최대 초과 출력 (kW)** | 필요한 배터리 출력 |
| **총 초과 에너지 (kWh)** | 필요한 배터리 용량 |
| 기본요금 절감액 | |
| 필요 ESS 사양과 개략 투자비 | 단가는 사용자 입력 |
| 단순 회수기간 | |
| **손익분기 배터리 단가** | 회수기간 10년이 되는 단가 역산 |

**출력(kW)과 에너지(kWh)를 분리해 보여주는 것이 핵심이다.** 목표를 조금만 낮추면
필요 에너지가 급감하는 경우가 많고, 그 사실이 배터리 사양을 완전히 바꾼다.

손익분기 단가 역산이 있으면 "지금은 경제성 없음"이라는 결론조차 의사결정 자료가 된다.

**디스패치** — 규칙기반 피크컷 단일 전략. 목표 초과분 방전, 경부하 시간대 충전.
MILP 최적화는 범위 밖이다.

### 7.5 잉여 활용

```
연간 잉여 발전량      ○○○ kWh  (전체 발전량의 ○%)
잉여 발생 시간대 분포  주말·연휴 집중 여부
─────────────────────────────────
시나리오 A  버림(자가소비만)              0원
시나리오 B  상계거래                      약 ○○○만원/년
시나리오 C  외부 신재생에너지 구매 연계   약 ○○○만원/년
```

**제도별 자격요건과 행정 절차는 별도 확인 필요**를 명시한다. 예상 행정 부담(계약 변경,
계량기, 정산 관리)을 한 줄로 병기한다. 자격 판정은 하지 않는다.

## 8. 조합 비교

선택한 수단들의 조합을 나란히 놓는다.

| 조합 | 절감액 | 투자비 | 회수기간 | **확실성** |
|---|---|---|---|---|
| 선택요금 전환만 | ○○ | 0 | 즉시 | 높음 |
| + 계약전력 조정 | ○○ | 0 | 즉시 | 높음 |
| + 태양광 ○○ kWp | ○○ | ○○ | ○년 | 중간 |
| + ESS ○○ kWh | ○○ | ○○ | ○년 | 중간 |

**확실성 등급을 반드시 표시한다.**

| 등급 | 대상 | 근거 |
|---|---|---|
| 높음 | 요금제 전환, 계약전력 조정 | 실측 데이터와 요금표만으로 확정 계산 |
| 중간 | 태양광 | 발전량 예측 오차 존재 |
| 중간~낮음 | ESS | 운전 전략과 열화에 좌우 |

같은 표에서 이를 구분해 보여주면 의사결정 품질이 달라진다.

**조합의 절감액은 단순 합이 아니다.** 태양광이 사용량을 줄이면 최적 선택요금이 바뀌고,
ESS가 피크를 낮추면 기본요금 기반이 달라진다. 조합마다 요금을 다시 계산한다.

## 9. 불확실성 처리

### 9.1 배경

태양광 발전량 예측은 **총량은 실측과 부합하나 피크 발전량이 과소 산출되는 경향**이 있다
(시간별 R² 약 0.8). 재분석·위성 일사 데이터의 공간·시간 평균화로 발전 프로파일이
평탄화되기 때문이다. 이 편향은 **피크 절감량을 과소 추정하는 방향**으로 작용하므로
결과가 이미 보수적이다.

### 9.2 감도 3종

확률 표기(P90 등)를 쓰지 않는다. 부하가 실측으로 고정되어 연도별 변동의 절반만
반영되므로 확률 표기는 통계적으로 정직하지 않다.

| 시나리오 | 기본 계수 |
|---|---|
| 보수 | PV 출력 × 0.70 |
| 기준 | PV 출력 × 1.00 |
| 낙관 | PV 출력 × 1.20 |

- 계수는 사용자 조정 가능
- 실측 발전 데이터가 있으면 피크 시간대(10~15시)의 예측 대비 실측 비율 분포에서 산출
- 다년 기상 반복 계산 불필요

**요금제 전환과 계약전력 조정에는 감도를 적용하지 않는다.** 확정 계산이다.

### 9.3 편차 보정 (옵션, 미구현)

분위수 사상(quantile mapping)으로 예측 분포를 실측 분포에 맞추는 기능.
총량을 보존하면서 상단을 복원한다. 실측 발전 데이터가 축적된 후 구현한다.

### 9.4 필수 경고

> 기본요금은 직전 12개월 중 최대수요로 결정됩니다. 계약전력을 하향할 경우,
> 예측 오차와 기상 변동을 고려하여 충분한 여유를 확보하십시오.
> 한 번의 초과가 12개월간 적용됩니다.

| 현재 요금 구조 | 기본요금 대 전력량요금, 시간대별 비중 |
| 계약전력 적정성 | 여유율과 하향 여지 |

**2단계 · 개선 수단** — 카드로 선택

수단마다 독립적으로 켜고 끈다. **투자비 순으로 배치한다.**

```
투자 0원   ─ 선택요금 전환
           ─ 계약전력 조정
투자       ─ 태양광
           ─ ESS
           ─ 잉여 활용
```

각 카드는 접힌 상태로 시작하고, 펼치면 그 수단의 입력과 결과가 나온다.

**3단계 · 비교**

선택한 조합의 절감액·투자비·회수기간·확실성을 나란히 표시한다.

### 10.2 UI 원칙

- 핵심 KPI 만 기본 표시, 옵션 조정값은 확장 패널 안에 감춘다
- 차트는 altair 또는 plotly
- 계산 결과는 `st.cache_data` 로 캐싱
- 드롭다운 선택지는 요금 데이터 파일에서 생성
- 계산 로직은 순수 함수를 호출만 한다. UI 에 계산을 넣지 않는다
- 업로드 데이터를 서버에 영구 저장하지 않는다

### 10.3 Excel 상세

시트 구성: 요약 / 진단 / 월별 집계 / 15분 시계열 / 요금 계산 명세 / 수단별 결과 / 조합 비교 / 감도.

**저장 직전 tz-aware 컬럼을 반드시 해제한다.**

for col in df.columns:

## 11. 검증

### 11.1 요금 엔진

가장 중요한 검증 대상이다. 우선순위대로 시도한다.

1. **실제 청구서 대조** — 확보 시 월별 기본요금·전력량요금을 ±1% 내로 재현
2. **자사 사옥·현장 사무소 청구서** — 종별이 달라도 계산 로직 검증에는 충분
3. **한전 공개 요금계산 서비스 대조** — 대표 케이스 몇 건
4. **수기 계산 단위테스트** — 요금표에서 직접 계산한 케이스 최소 5건

최소 4번은 반드시 구현한다. 1~3번 중 하나 확보를 인수 조건으로 한다.

### 11.2 단위테스트 필수 항목

| 항목 |
|---|
| `24:00` 표기 파싱 |
| 검침일 라벨 규약 (구간 끝) |
| 15분 최대수요 산출 |
| 요금적용전력 — 경부하 시간대 제외 |
| 요금적용전력 — 대상월(7·8·9·12·1·2 + 당월) |
| 요금적용전력 — 계약전력 30% 하한 |
| 대상월과 전력량요금 계절이 다름 (9월·6월·11월) |
| 계절·시간대 경계 (5/31 23시, 6/1 0시, 겨울 12시 경계) |
| 토요일 최대부하 → 중간부하 계량 |
| 일요일·공휴일 경부하 계량 |
| 임시공휴일 사용자 추가·제외 |
| 산업용(을) 봄·가을 주말 할인 |
| 결측 구간 제외 계산 |
| 부분 월 처리 |
| 부하·PV 시각 정렬 (15분 어긋남 검출) |
| 감도 계수 적용 |
| 조합 시 요금 재계산 (단순 합이 아님) |

### 11.3 케이스 스터디

실측이 1건뿐이므로 샘플을 변형해 합성 케이스를 만든다.

| 케이스 | 성격 |
|---|---|
| C1 오전 피크형 | 원본 (10~13시 집중) |
| C2 오후 피크형 | 프로파일 5시간 이동 |
| C3 평탄형 | 부하율 85%, 데이터센터 성격 |
| C4 주말 가동형 | 공장 성격 |
| C5 겨울 피크형 | 겨울 오전 피크 |

여기에 PV 용량 4단계 × 선택요금 전 조합 × 감도 3종을 겹친다.

**타당성 자동 판정** — 물리적으로 성립해야 하는 관계를 테스트로 만든다.

- PV 0 kWp 일 때 PV 절감액이 정확히 0
- PV 용량 증가 시 전력량요금 절감액 단조 증가
- 기본요금 절감액은 단조 증가 후 포화
- **C2 < C1** (기본요금 절감액) — PV 시간대와 피크가 어긋나므로
- C3 평탄형은 기본요금 절감이 거의 없음
- 감도 보수 < 기준 < 낙관
- 요금제 전환 절감액은 감도와 무관하게 일정

**경계 케이스** — 12개월 미만, 역년 아닌 기간, 1시간 간격, 결측률 10%,
계약전력 초과 구간 포함.

### A.2 검증 규칙 (단위테스트 필수)

단가를 수기로 옮길 때의 오타는 결과가 그럴듯하게 나와 발견하기 어렵다.
요금표 자체의 구조적 규칙을 테스트로 만들어 자동 검출한다.

**규칙 1 — 순서 관계**

- 모든 계절·전압·선택요금에서 `경부하 < 중간부하 < 최대부하`
- 기본요금: `선택Ⅰ < 선택Ⅱ < 선택Ⅲ`
- 전력량요금: `선택Ⅰ > 선택Ⅱ > 선택Ⅲ`
- `여름철 최대부하 > 봄·가을철 최대부하`

**규칙 2 — 선택요금 간 단가 차이 (적용 범위 한정)**

| 쌍 | 차이 | 균일성 검사 | 허용오차 |
|---|---|---|---|
| 고압A Ⅰ→Ⅱ | 5.5 원 | 적용 | ±0.05 |
| 고압B Ⅰ→Ⅱ | 3.8 원 | 적용 | ±0.05 |
| 고압B Ⅱ→Ⅲ | 1.6~1.7 원 | 적용 | **±0.15** (반올림 폭) |
| 고압A Ⅱ→Ⅲ | 0.6~12.4 원 | **미적용** | — |

**고압A Ⅱ→Ⅲ 는 할인이 최대부하에 집중된 구조다.** 경부하·중간부하는 0.6~1.3 원인데
최대부하는 8.3~12.4 원이다. 사용시간이 긴 고객을 겨냥한 의도적 설계이므로 균일하지 않은
것이 정상이다. 대신 아래를 검사한다.

- 최대부하 할인폭 > 중간부하 할인폭
- 최대부하 할인폭 > 경부하 할인폭

**규칙 3 — 손익분기 이용시간**

```
손익분기 이용시간(h/월) = 기본요금 차이 ÷ 전력량요금 차이
```

| 쌍 | 산출값 | 허용 범위 | 근거 |
|---|---|---|---|
| 고압A Ⅰ→Ⅱ | 1,100 ÷ 5.5 = 200 h | 150~250 | |
| 고압B Ⅰ→Ⅱ | 750 ÷ 3.8 = 197 h | 150~250 | |
| 고압B Ⅱ→Ⅲ | 810 ÷ 1.65 ≈ 491 h | 400~600 | 요금표 안내 "월 500시간 초과 고객에게 유리"와 일치 |
| 고압A Ⅱ→Ⅲ | 단일값 불성립 | — | 부하구성 의존 (전부 최대부하 120 h ~ 전부 경부하 1,656 h) |

**요금표의 선택요금 안내 문구와 산출값이 맞는지 대조하는 것이 가장 강력한 검증이다.**

**규칙 4 — 시간대 정의의 완전성**

- 각 계절의 경/중간/최대부하 구간 합이 정확히 24시간, 중복 없음

### A.3 드롭다운 생성

계약종별·전압구분·선택요금 선택지는 **하드코딩하지 않고 요금 데이터 파일에서 생성한다.**
데이터에 없는 조합은 선택지에 나타나지 않아야 한다.

### A.4 단계적 확장

PoC는 **일반용전력(을) 고압A·B만** 구현하고 검증한다. 통과 후 아래 순서로 확장하며,
확장 시에도 A.2 검증 규칙을 통과해야 한다.

1. 일반용전력(갑)Ⅰ·Ⅱ
2. 산업용전력(갑)·(을) — 주말 할인 특례 포함
3. 교육용전력(갑)·(을) — 임계값 1,000 kW 주의

## 부록 D. 알려진 한계

산출물과 README에 명시한다.

1. 기본요금과 전력량요금만 계산한다. 기타 요금요소는 미포함이며, 이들이 사용전력량에
   비례하므로 실제 절감액은 본 결과보다 크다.
2. 태양광 발전량 예측은 피크 발전량을 과소 산출하는 경향이 있다. 피크 절감량이 보수적으로 나온다.
3. 역률요금은 추정값 기반 참고 산출이다. 무효전력 실측이 없다.
4. 결측 구간에 더 큰 수요가 있었을 수 있다.
5. 부하는 업로드한 데이터가 고정이다. 향후 운영 변화(공실률, 증설, 용도 변경)는 반영하지 않는다.
6. 인증·신고용 산출물이 아니다.
7. 상계거래·외부 신재생에너지 구매의 자격요건은 판정하지 않는다. 금액만 참고로 제시한다.
8. ESS 디스패치는 규칙기반 단일 전략이다. 최적 운전과는 차이가 있다.
