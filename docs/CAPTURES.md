**두 가지가 이 문서에 있다. 섞지 마라.**

| | 매뉴얼용 (아래 C-01~C-11) | 확인용 (S157 절) |
|---|---|---|
| 무엇에 쓰나 | `MANUAL.md` 에 넣는다 | 사람이 화면을 보기 전에 **무엇이 그려지는지** 본다 |

넣지 않는다. 여기 함께 두는 것은 **찍을 자리 목록이 한 자리에 있어야** 다음
판이 두 벌을 다시 세지 않기 때문이다.

## 매뉴얼용 캡처

매뉴얼(`MANUAL.md`)에 캡처 자리를 잡아 두었다. **사람이 찍어 넣는다.**

html 에서는 점선 상자로 표시되며, 그 자리에 `![캡처 C-0x] 캡션` 한 줄이 있다.
이미지를 넣으려면 그 줄을 아래 형식으로 바꾼다.

```
![캡처 C-01] 앱 첫 화면 — 왼쪽 옆단의 네 가지 화면과 파일 업로더
```

**단일 파일 규약을 지키려면 base64 로 넣어야 한다.** 외부 파일을 참조하면
html 하나만 옮겼을 때 그림이 깨진다. 넣는 방법은 [아래](#넣는-법)에 있다.

## 찍는 요령

- **브라우저 창을 1280×800 안팎**으로 맞춘다. 더 넓으면 글자가 작아 보인다.
- 실제 샘플(`input\사용량조회_20240429.csv`)로 찍는다. 빈 화면은 쓸모가 없다.
- 개인정보·고객명이 보이지 않게 한다. 샘플에는 없다.
- 확대는 100%. 브라우저 확대는 캡처에 그대로 남는다.
- **잘라내기는 화면 요소 단위로.** C-05 처럼 "두 차트"라고 적힌 것은 둘 다 담는다.

## 넣는 법 {#넣는-법}

1. png 로 저장한다.
2. base64 로 바꾼다.

```
.venv\Scripts\python.exe -c "import base64,pathlib,sys; print(base64.b64encode(pathlib.Path(sys.argv[1]).read_bytes()).decode())" C-01.png
```

3. `MANUAL.md` 의 해당 줄을 바꾼다.

```
<img alt="앱 첫 화면" src="data:image/png;base64,iVBORw0KG...">
```

4. 다시 만든다.

```
.venv\Scripts\python.exe tools\build_docs.py
```

> **외부 파일을 참조하지 마십시오.** `src="images/c01.png"` 처럼 쓰면 html
> 하나만 옮겼을 때 그림이 깨집니다. 시험이 이를 잡습니다.
