**46세션의 「뜰 수 없는 경고」** — `PROCEED.md` 15721·16149행이 「가장자리 경고 (`_missing_input`)」
로 가리킨다. 이 판에서 그 자리를 다시 열지 않았다 — 위 표의 「뜰 수 없는」 둘(②-33 · ②-35)이
같은 꼴이다.

**뜨는지 못 잰 것.** `notices` 를 만드는 자리 **95곳**(`Notice(`·`warn(`·`basis(` 호출 — 저장소)
가운데 벌 스물셋에서 실제로 뜨는 사실 ID 가 몇인지는 **못 쟀다** — 벌을 다 돌려 사실 ID 를
모아야 한다(케이스 스터디 3분 + 덱 열하나). 재는 길은 6절에 적는다.
