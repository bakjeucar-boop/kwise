# 사람이 화면을 열어 한 판에 잡을 글자 — 문구 판 목록 열아홉

**S251 4-2 가 모았다.** 미해결 가운데 「문구 판」(글자 · 이름 · 자리를 사람이 화면과 산출물을
열어 정하는 몫)을 **화면 순서대로**(1단계 → 2단계 → 3단계 → 산출물) 한 표에 세웠다. 값은
S250 뒤 덱 스냅(`cache\deck_words\s250_after.json` · 19벌)에서 셌다 — S251 2절이 고친 자리
(PPT 상향 권고 · Excel 조합 비교 「없음」 · Word 감도 표 · 세로축 이름 · 금액 축 눈금)는 그 스냅과
지금 실물이 다르다. 경위는 `PROCEED.md` 251세션 절 4-2.

**여기에 고칠 안을 쓰지 않는다** (`SCREEN_WORDING_S157.md` · `SCREEN_WORDING_S204.md` 와 같은
규약). 담는 것은 「어디에 · 지금 무엇이 · 무엇이 걸리나 · 걸린 결정」 까지다. 잣대는
`CLAUDE.md` 「화면 문구」 절이다 — 늘리지 않는다 · 이름을 먼저 고친다 · 하나를 더하면 무엇을
뺄지 함께 정한다.

**번호는 「지금 번호 [250세션 절 4-2 번호]」 다.** 「나」 는 S250 이 닫은 몫만큼 당겨졌다.
