## 어떻게 쟀나

- **자료 둘** — 맨 위 상자의 경로 그대로. 다른 파일은 안 열었다.
- **PDF 는 `pypdf` 로 글자를 떴다.** `.venv` 에는 PDF 를 읽을 것이 없어
  시스템 python (`…\Python312\python.exe`, pypdf 6.16.2) 의 것을 썼다 —
  **아무것도 설치하지 않았다.** `pdftotext` 는 이 PDF 에서 한글이 사라진다.
- **계절 열은 자리가 아니라 머리글 이름으로 맞췄다.** 시트마다 순서가 다르다 —
  일반용·교육용은 「여름·봄가을·겨울」, **산업용은 「봄가을·여름·겨울」** 이다.
  PDF 는 세 표 다 「여름·봄가을·겨울」 이다.
- **PDF 는 세로쓰기가 낱자로 흩어져 나온다** (「고 압 A」 · 「선 택 Ⅰ」).
  낱자를 이어 붙여 전압·선택요금 맥락을 세운 뒤 값 줄을 읽었다.
- **종별 구간은 사람이 눈으로 붙였다.** PDF 본문에 종별 이름이 안 뜨고
  「＊ 계약전력 300kW미만」 같은 조건만 뜨기 때문이다. 붙인 구간은 이렇다
  (`pypdf` 로 뜬 글의 줄 번호).

  | 종별 | 줄 | 꼴 | 쪽에서 뜬 표시 |
  |---|---|---|---|
  | 교육용(갑) | 22–37 | 비TOU | ＊ 계약전력 1,000kW미만 |
  | 교육용(을) | 38–84 | TOU | ＊ 계약전력 1,000kW이상 |
  | 일반용(갑)Ⅰ | 100–115 | 비TOU | ＊ 계약전력 300kW미만 |
  | 일반용(갑)Ⅱ | 116–178 | TOU | ＊ … 시간대별 구분계량기 설치고객 |
  | 일반용(을) | 179–239 | TOU | ＊ 계약전력 300kW이상 |
