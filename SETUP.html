kWise
설치 및 시작 안내

건물 전력 비용 진단 및 개선안 비교. 운영 중 건물의 15분 실측 전력 데이터로 비용 구조를 진단하고, 요금제 전환·계약 조정·태양광·ESS 등 개선 수단의 효과를 같은 기준으로 비교합니다.

대상 OS
Windows 10 1809+ / 11
Python
3.12 (3.13 이상 금지)
작업 도구
Claude Code
소요
설치 20분 · 1세션 1~2시간
Step 0

받은 파일 확인

kwise_setup.zip 안에 요구사항 일체가 들어 있습니다. 코드는 없습니다 — 코드는 Claude Code가 이 문서들을 읽고 만듭니다.

kwise_setup.zip ├─ SETUP.html 지금 보고 계신 문서 ├─ PROJECT_GUIDE.html 세션별 프롬프트와 순서 ├─ CLAUDE.md Claude Code가 매 세션 자동으로 읽는 규칙 ├─ PROCEED.md 진행 이력 — 이전 세션 결정사항이 채워져 있음 └─ docs/ ├─ ENVIRONMENT.md 실행 환경 제약 └─ REQUIREMENTS_kwise.md 요구사항서 (본문)

여기에 더해 직접 준비하실 파일이 있습니다.

reference\ 기존 pv_peak_cut 저장소에서 ├─ mg_pv_core.py ├─ mg_weather_openmeteo.py └─ streamlit_app.py input\ 샘플 15분 실측 데이터 └─ 사용량조회_20240429.csv
이전 저장소를 옮길 수 있다면. 안드로이드에서 3세션까지 작업한 폴더를 통째로 가져오면 코드와 커밋 이력이 보존됩니다. 그 경우 CLAUDE.md와 docs\ENVIRONMENT.md 두 파일만 이 묶음의 것으로 교체하고, PROCEED.md는 기존 것을 유지하십시오. 옮기지 못하더라도 이 묶음의 PROCEED.md에 1~3세션 결정사항 12건이 모두 담겨 있습니다.
Step 1

기존 설치 정리

애매하게 설치된 것들을 먼저 지웁니다. 이 단계를 건너뛰면 나중에 어느 환경에서 실행되고 있는지 알 수 없게 됩니다.

가상환경과 작업 폴더

현재 (peakcut) 또는 (.venv) 프롬프트가 보이면 가상환경이 활성화된 상태입니다. 먼저 빠져나옵니다.

PowerShell
deactivate
cd C:\
Remove-Item C:\Users\SAMSUNG\Documents\peakcut -Recurse -Force
폴더 안에 남길 파일이 있는지 먼저 확인하십시오. 기존 코드나 샘플 CSV를 이미 넣어 두셨다면 다른 곳으로 복사한 뒤 지우십시오. Remove-Item은 되돌릴 수 없습니다.

uv 제거

이 프로젝트는 표준 venv와 pip만 씁니다. 앞서 설치한 uv는 필요 없습니다.

PowerShell
python -m pip uninstall uv -y

PowerShell 프로필 확인

앞서 $PROFILE에 환경변수를 넣으셨다면 지웁니다. Step 2에서 더 나은 방법으로 다시 설정합니다.

PowerShell — 내용 확인
Get-Content $PROFILE -ErrorAction SilentlyContinue

PYTHONUTF8이나 PROJECT_CACHE 줄이 보이면 메모장으로 열어 그 줄만 지우십시오. 아무것도 출력되지 않으면 넘어가시면 됩니다.

PowerShell — 필요할 때만
notepad $PROFILE
실행 정책은 그대로 두십시오. 앞서 설정한 Set-ExecutionPolicy RemoteSigned -Scope CurrentUser는 가상환경 활성화에 필요합니다. 되돌리지 마십시오.
Step 2

사전 설치 확인

이미 갖춰진 것이 많습니다. 확인만 하고 없는 것만 설치합니다.

PowerShell — 확인
python --version
pip --version
git --version
claude --version
항목기대 출력없으면
PythonPython 3.12.x python.org에서 3.12 계열 64-bit. 설치 첫 화면에서 Add python.exe to PATH 체크
pippip 25.x 이상 python -m ensurepip --upgrade
Gitgit version 2.x git-scm.com에서 설치
Claude Code버전 문자열 irm https://claude.ai/install.ps1 | iex
Python 3.13 이상은 쓰지 마십시오. 일부 과학 계산 패키지가 새 Python 지원이 늦어 설치가 실패할 수 있습니다. Microsoft Store 창이 뜨면 PATH 체크를 놓친 것이니 설치 파일을 다시 실행해 Modify → Add to PATH를 켜십시오.

환경변수 — 한 번만

한국어 Windows는 콘솔 기본 코드페이지가 cp949라 UTF-8 파일에서 UnicodeDecodeError가 자주 납니다. 미리 막아둡니다.

PowerShell — 1회만
[Environment]::SetEnvironmentVariable("PYTHONUTF8", "1", "User")
[Environment]::SetEnvironmentVariable("PROJECT_CACHE", "$env:LOCALAPPDATA\kwise\cache", "User")

설정 후 PowerShell 창을 닫았다 다시 엽니다. 확인은 이렇게 합니다.

PowerShell — 새 창에서
$env:PYTHONUTF8
$env:PROJECT_CACHE

1과 캐시 경로가 나오면 됩니다.

왜 $PROFILE이 아니라 이 방법인가. SetEnvironmentVariable은 Windows 사용자 환경변수에 직접 등록하므로 PowerShell뿐 아니라 CMD, VS Code 터미널, Claude Code가 띄우는 Git Bash에서도 똑같이 적용됩니다. $PROFILE은 PowerShell에서만 동작합니다.

Claude Code 로그인 확인

PowerShell
claude doctor

설치 상태와 설정을 진단해 무엇이 잘못됐는지 알려줍니다. 문제가 생기면 가장 먼저 이 명령을 쓰십시오.

계정 요건. Claude Code는 Pro, Max, Team, Enterprise 또는 Console 계정이 필요합니다. 무료 플랜으로는 동작하지 않습니다. 처음 claude를 실행하면 브라우저가 열리며 로그인을 요구합니다.
Step 3

작업 폴더 준비

경로에 한글이나 공백이 없는 위치를 고르십시오. 일부 파이썬 패키지가 한글 경로에서 문제를 일으킵니다. OneDrive 동기화 폴더도 피하십시오.

PowerShell
mkdir C:\work\kwise
cd C:\work\kwise
mkdir docs, input, output, data, reference, src\kwise, tests
mkdir "$env:LOCALAPPDATA\kwise\cache" -Force
git init

파일 배치

zip을 이 폴더에 풀고, 기존 코드와 샘플 데이터를 넣습니다.

C:\work\kwise\ ├─ SETUP.html ├─ PROJECT_GUIDE.html ├─ CLAUDE.md ├─ PROCEED.md ├─ .gitignore 아래에서 생성 ├─ docs\ │ ├─ ENVIRONMENT.md │ └─ REQUIREMENTS_kwise.md ├─ reference\ 기존 코드 3개 — 이관이 끝나면 삭제 │ ├─ mg_pv_core.py │ ├─ mg_weather_openmeteo.py │ └─ streamlit_app.py ├─ input\ │ └─ 사용량조회_20240429.csv ├─ data\ output\ src\kwise\ tests\ 비어 있음

reference\를 저장소 안에 두는 이유는 Claude Code가 이관 대상 코드를 직접 읽어야 하기 때문입니다.

.gitignore

PowerShell
@"
output/
__pycache__/
*.egg-info/
build/
dist/
.venv/
venv/
cache/
.pytest_cache/
.ruff_cache/
.mypy_cache/
"@ | Set-Content .gitignore -Encoding UTF8

input/은 일부러 넣지 않았습니다. 케이스 스터디 데이터를 이력으로 남겨야 검증 결과를 재현할 수 있습니다.

가상환경 만들기

시스템 Python을 더럽히지 않도록 프로젝트 전용 환경을 만듭니다.

PowerShell
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip

프롬프트 앞에 (.venv)가 붙으면 활성화된 것입니다. PowerShell을 새로 열 때마다 .venv\Scripts\activate를 다시 실행해야 합니다.

실행이 차단되면 Set-ExecutionPolicy RemoteSigned -Scope CurrentUser를 한 번 돌리십시오. 이미 하셨다면 다시 할 필요 없습니다.

패키지 설치는 1세션에서 Claude Code가 합니다. 미리 확인만 하시려면 이렇게 합니다.

PowerShell — 선택
pip install pandas numpy pvlib holidays streamlit openpyxl pyarrow pytest ruff mypy
Step 4

첫 세션 시작

작업 폴더에서 Claude Code를 시작합니다. CLAUDE.md는 저장소 루트에 있으면 자동으로 읽히므로 따로 첨부할 필요가 없습니다.

PowerShell
cd C:\work\kwise
.venv\Scripts\activate
claude

세션이 열리면 PROJECT_GUIDE.html의 05장에서 1세션 프롬프트를 복사해 붙여넣으십시오.

가상환경 주의. Claude Code가 명령을 실행하는 셸은 .venv가 활성화되어 있지 않을 수 있습니다. 그러면 pytest가 패키지를 못 찾습니다. 첫 세션 시작 때 한 줄 알려주십시오 — “이 프로젝트는 .venv 를 쓴다. python 실행은 .venv\Scripts\python.exe 로 해줘.” CLAUDE.md에도 같은 내용이 적혀 있습니다.

막힐 때

증상원인과 대처
'irm' is not recognized PowerShell이 아니라 CMD입니다. 프롬프트가 PS C:\…로 시작하는지 확인하십시오.
claude 명령을 못 찾음 %USERPROFILE%\.local\bin이 사용자 PATH에 있는지 확인. 설치기가 추가하지만 일부 환경에서 누락됩니다.
스크립트 실행이 차단됨 Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
다운로드한 .ps1이 “디지털 서명되지 않았습니다” 인터넷에서 받은 파일의 차단 표시입니다. Get-ChildItem -Recurse | Unblock-File
한글이 ?묒꽦 처럼 깨짐 PYTHONUTF8 미설정, 또는 .ps1이 BOM 없는 UTF-8입니다. Windows PowerShell 5.1은 한글이 든 스크립트를 BOM 없이 읽지 못합니다.
Git Bash를 못 찾음 %USERPROFILE%\.claude\settings.json에 {"env":{"CLAUDE_CODE_GIT_BASH_PATH":"C:\\Program Files\\Git\\bin\\bash.exe"}} 추가
PermissionError (xlsx) Excel이 파일을 열고 있습니다. 닫고 다시 실행하십시오.
pytest가 패키지를 못 찾음 .venv 미활성화입니다. .venv\Scripts\activate 실행 후 재시도.
로그인 브라우저가 안 열림 추적 차단이 강한 브라우저에서 자주 발생합니다. 기본 브라우저를 바꿔 보십시오.

사내망 프록시 환경이라면 방화벽에서 claude.ai, api.anthropic.com, downloads.claude.ai 접근이 필요합니다.
